# Brainrot University (BU)

> **"Educating the Chronically Online Since Never."**  
> *"Your degree is worthless. Your aura is priceless."*

Brainrot University is a satirical, fully functional web application exploring internet culture, Gen Z humor, and absurd academic rigor. Built with modern React, TypeScript, Tailwind CSS v4, and Framer Motion.

---

## 🏛️ Features

- **5 Dedicated Departments**:
  - Department of Delusion Studies
  - Department of Unproductive Sciences
  - Department of Rizz Engineering
  - Department of Grass Studies
  - Department of Brainrot Technology
- **26 Interactive Courses & Full Syllabi**: From *Advanced Overthinking 101* to the classified *SECRET-666: The Forbidden Curriculum*.
- **Interactive Examination Hall**: Real multi-step quiz engine with timed questions, answer review, and instant satirical feedback.
- **Dynamic Grading Engine**:
  - `SIGMA SUMMA CUM LAUDE` (95–100%)
  - `CERTIFIED AURA ENGINEER` (85–94%)
  - `FUNCTIONAL NPC` (70–84%)
  - `ACADEMICALLY COOKED` (50–69%)
  - `PROFESSIONAL DELULU` (25–49%)
  - `DROP-OUT IN SPIRIT` (0–24%)
- **Cursed Certificate Generator**: Downloadable (PNG via `html2canvas`) and printable high-resolution academic diplomas with unique serial codes and official seals.
- **Academic Titles & 25 Achievements**: Real unlocking logic persisted locally in `localStorage`, tracking stats, night owl habits, speedrunning, and secret conditions.
- **Secret Dimension & Easter Eggs**:
  - Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`) activates maximum brainrot mode.
  - Clicking the crest 7 times unlocks the forbidden sector and hidden course.
- **Student Portal**: Virtual Student ID Card, grade transcripts, course progression, achievement showcase, and expulsion reset zone.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run preview
```
